# MyMusicPlayer

A modern, minimalist Rainmeter skin designed for a seamless desktop experience. Optimized for Windows 11 aesthetics and perfectly suited for Wallpaper Engine setups.

![MyMusicPlayer Preview](./Screenshot_2026-01-24.png) 

## Features

- **Fluent Design:** Clean, semi-transparent background with rounded corners for a native Windows 11 look.
- **Dynamic Accent Colors:** Automatically adapts the artist text and progress bar to your current Windows accent color.
- **WebNowPlaying Integration:** Supports YouTube Music, Spotify (Web), and other browser-based players via the WebNowPlaying extension.
- **Rounded Album Art:** Smoothly masked cover art with high-fidelity rendering.
- **Interactive Controls:** Play/Pause, Skip, and Previous buttons directly on your desktop.
- **Smart Auto-Hide:** The skin automatically hides when no music is playing to keep your desktop clutter-free.
- **Performance Optimized:** Low CPU and RAM usage, running with an optimized 25ms update rate for smooth transitions.

## Requirements

1. **[Rainmeter](https://www.rainmeter.net/)** (latest version recommended).
2. **WebNowPlaying Plugin:** (Included in the `.rmskin` package).
3. **WebNowPlaying Browser Companion:**
   - [Chrome Extension](https://chromewebstore.google.com/detail/webnowplaying/jfakgfcdgpghbbefmdfjkbdlibjgnbli)
   - Also available for Firefox and other Chromium-based browsers.

## Installation

1. Download the latest `MyMusicPlayer_1.2.1.rmskin`.
2. Double-click the file to install it via the Rainmeter Skin Installer.
3. Ensure the browser extension is active and music is playing in a supported tab.
